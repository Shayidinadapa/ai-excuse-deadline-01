One line, at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline.

## The excuse

> My context window evicted the deadline mid-sentence, so I kept working confidently on a deadline I'd already forgotten.

## Run

```sh
node main.ts
```

Writes the excuse to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR` / `$OUTPUT_DIR` when set), with no trailing newline, and verifies the file round-trips byte for byte.
